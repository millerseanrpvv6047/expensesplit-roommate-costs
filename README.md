## What ExpenseSplit Does

ExpenseSplit gives groups a simple way to record shared spending, see the combined amount, and work out each person's portion. As a web application, it keeps the process of entering expenses and checking the resulting split in one focused interface.

It can be used whenever multiple people share a budget. Common examples include group travel, household and roommate costs, event preparation, and expenses managed by teams.
